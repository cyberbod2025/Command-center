# Command Center Dashboard

Primera versión operativa (no productiva) del panel de decisión y acción del
portafolio de Hugo. Ver `docs/` para el detalle completo:

- [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) — estructura y separación de responsabilidades.
- [`docs/DATA-MODEL.md`](docs/DATA-MODEL.md) — modelo de datos y máquina de estados.
- [`docs/INTEGRATIONS.md`](docs/INTEGRATIONS.md) — GitHub, Teacher OS, Supabase.
- [`docs/SECURITY.md`](docs/SECURITY.md) — reglas de seguridad y por qué la app nunca finge una ejecución.
- [`docs/RUNNING.md`](docs/RUNNING.md) — cómo instalar y correr localmente.
- [`docs/LIMITATIONS.md`](docs/LIMITATIONS.md) — limitaciones conocidas de esta entrega.
- [`docs/ROADMAP.md`](docs/ROADMAP.md) — próximos pasos propuestos, no aprobados.

Arranque rápido:

```bash
cd dashboard
npm install
npm run dev
```

Luego abre `http://localhost:4173`.
